# Karyatim Public UI

The shipped direction is **Site Record Board**: a restrained, technical company profile built from corporate-blue planes, real field photography, registration rules, and compact project metadata.

## Design authority

`PRODUCT.md` is the complete authority for company facts, source assets, tokens, components, responsive behavior, route contracts, and extension rules. This file is the quick implementation index.

## Reuse first

- Tokens and primitives: `resources/css/app.css` (`.kt-*`).
- Public shell: `AppLayout`, `Navbar`, and `Footer`.
- Evidence patterns: `ProjectCard` and `ClientLogoGrid`.
- Approved compositions: split documentary hero, ruled register, asymmetric evidence grid, and 12-column editorial detail.

Do not introduce a parallel palette, rounded card system, decorative gradients, unsupported claims, stock imagery, or alternate logo treatment. New public pages must preserve the existing Inertia props, Laravel routes, and inquiry fields.
