# Antigravity Project Rules

Baca `AGENTS.md` di root repository **satu kali** pada awal task. Jangan baca berulang.

Ikuti semua aturan di `AGENTS.md`:
- Efisiensi konteks: mulai dari `git status`/`git diff`, baca file bertahap, jangan scan seluruh codebase.
- Testing: test spesifik dulu, jangan jalankan seluruh suite setelah perubahan kecil.
- Keselamatan Git: jangan commit/push/reset tanpa instruksi eksplisit.
- Caveman Lite: hilangkan filler dan narasi, pertahankan detail teknis.
- Handoff: periksa dan perbarui `docs/AI_HANDOFF.md` sesuai aturan.

Pahami prompt percakapan atau chat klien mentah tanpa meminta format khusus.

Jangan menarasikan setiap tool call atau command — langsung kerjakan.
