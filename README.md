# PT. Karyatim Mandiri Engineering — Company Profile & Portfolio

Official modern company profile website and interactive civil engineering portfolio for **PT. Karyatim Mandiri Engineering** (Surabaya, Indonesia).

## Tech Stack
- **Backend**: Laravel 12 / 13 (PHP 8.2+)
- **Frontend**: Inertia.js v2, React 19, Tailwind CSS v4, Lucide React
- **Design Standard**: Anti-AI-Slop Standard & Sangkolo Ecosystem Identity (`#0c253b`, `#97ad82`, `#fffdf8`, `#081a2a`)
- **Interactive Features**: 
  - Real project catalog with dynamic category filters & quick view modal
  - Interactive Construction Cost & RAB Estimator with 1-click WhatsApp inquiry payload
  - Service directory with technical deliverables
  - Corporate client showcase
  - Official PDF portfolio download

## Deployment
Managed and deployed via Farovel on `karyatim.sangkolo.my.id`.
